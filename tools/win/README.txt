Saber Rider and the Star Sheriffs - demo reconstruction, Windows x86-64

Run saber_rider.exe (from a command prompt: saber_rider.exe --level N to start on stage N, 1-6).
It is a single static executable. data\ holds the original demo's .pck packs, which the game reads directly.

Controls: arrows move, W/A jump, S/D shoot, hold Q/E to aim (8 directions), X/F power attack,
Enter starts / pauses, Alt+Enter toggles fullscreen. Down+jump slides; down+jump on a platform drops through.
Gamepad: d-pad/stick, South jump, East/West shoot, North power attack, shoulders aim, Start pause.

OPTIONS sets the screen (fullscreen / window size), ratio and filter. OPTIONS > CONTROLS remaps the keyboard and
the gamepad (confirm a slot, then press the new key or button; Esc cancels, Del clears). The bindings are saved
in %APPDATA%\SaberRider\SaberRider\controls.cfg.
